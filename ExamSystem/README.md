# نظام إدارة الامتحانات - Exam Management System

## نظرة عامة
نظام متكامل لإدارة الامتحانات مبني بلغة Delphi 10.3 وقاعدة بيانات Firebird 5.0

## المتطلبات
- Delphi 10.3 Rio أو أحدث
- Firebird 5.0 Database Server
- FireDAC (مضمن في Delphi)

## التثبيت

### 1. قاعدة البيانات
1. قم بتثبيت Firebird 5.0
2. أنشئ قاعدة البيانات باستخدام ملف SQL المرفق
3. عدل إعدادات الاتصال في `uGlobals.pas`:
   - DB_SERVER: عنوان الخادم
   - DB_PATH: مسار قاعدة البيانات
   - DB_USER: اسم المستخدم
   - DB_PASSWORD: كلمة المرور

### 2. بناء التطبيق
1. افتح `ExamSystem.dpr` في Delphi 10.3
2. تأكد من تثبيت مكونات FireDAC
3. اضغط F9 للبناء والتشغيل
